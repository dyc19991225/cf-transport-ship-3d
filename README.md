# 穿越火线 3D：运输船 (CrossFire: Transport Ship TD)

**在线即玩地址 (GitHub Pages)**：https://dyc19991225.github.io/cf-transport-ship-3d/

基于 **Three.js + TypeScript + WebAudio** 原生打造的 3D 第一人称团队竞技枪战游戏，1:1 战术级还原《穿越火线》（CF）最具代表性的经典地图 **运输船 (TD_Ship)**。

## 核心还原特性

### 1. 经典运输船立体结构全还原
- **严密 180° 中心对角对称货轮甲板**：保卫者（Global Risk，舰桥侧）与潜伏者（Black List，船首侧）双阵营独立室内基地舱、双出口卡点与门前横箱。
- **中路核心集装箱群 & 开口铁皮通道**：还原中路可穿行的开口红集装箱（支持内部突袭与借阶梯木箱登顶集装箱）以及双层堆叠货柜。
- **天然“爆头线”与可穿透木箱（穿箱系统）**：集装箱与木箱横缝严格对齐站立头部高度（`Y = 1.68m`），支持真实的木箱子弹穿透伤害衰减与穿箱击杀判定。
- **双侧狙击高台（制高点）**：双方基地前右侧均设有架点高台，支持斜坡直上或利用阶梯木箱蹲跳快上。
- **双侧地下暗道（下水道）**：甲板下方贯通东西两侧的隐蔽钢制底舱通道，支持静步摸家绕后偷袭。
- **完整远洋货轮外景**：6 层白色舰桥驾驶楼、旋转海事雷达、红黑烟囱、双座黄色龙门吊塔、船首破浪锚甲板以及自定义 GLSL 动态海浪与船体白沫 Shader。

### 2. 经典四套战术背包 & 真实枪感
- **背包 1 · AK-47 火麒麟涂装**：高后坐力高爆发，无视头盔一枪黄金爆头。
- **背包 2 · M4A1-S 迷彩消音**：紧凑速射消音器声效，高达 **84%** 的传奇穿木箱伤害保留率。
- **背包 3 · AWM-A 绿皮狙击**：支持右键 **2.6x / 6.0x** 双倍开镜，经典打腿 83 血、胸头一击必杀，完美支持 **`Q` 键切枪瞬狙**。
- **背包 4 · Barrett M82A1 巴雷特大炮**：重型反器材巨响，隔木箱全身满伤一击必杀（大炮穿箱死）。
- **副武器 / 近战 / 投掷**：**沙漠之鹰**、**尼泊尔军刀**（切刀旋转动作、轻刀快砍、右键重刀秒杀、切刀 +16% 移速赶路）、**高爆手雷**（支持集装箱几何反弹与 `Fire in the hole!` 无线电音效）。

### 3. CF 标志性竞技反馈与 AI 团竞
- 支持 **5v5 / 8v8** 友军与敌军同场对抗（含高台架狙手、暗道老六、中路突破手多路线寻路 AI）。
- 黄金爆头头盔清脆音效、双连杀至超神暴走星翼勋章、实时旋转战术雷达、受击方向红弧指示、3 秒金色复活无敌护盾、随时可开启的 **3D 航拍全景视角 (`P` 键)** 以及移动端虚拟摇杆触控适配。

## 本地运行与构建

```bash
npm install
npm run dev
npm run build
```
